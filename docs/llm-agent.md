## 🏛️ LLM Agent 的四大核心支柱

我们可以用一张图表和架构拆解，把它们之间的关系理清楚：

### 1. 核心大脑 (The Core Brain) —— **LLM**

这是整个 Agent 的计算核心与决策中枢。

* **职责**：负责理解用户的意图，进行逻辑推理、规划步骤，并决定什么时候该干什么。
* **你提到的：** **LLM** 就在这里，它是所有逻辑和思考的物理载体。

### 2. 控制、反思与规划 (Planning & Control) —— **Prompt & Context**

这决定了大脑如何思考，以及它能看多远。

* **规划 (Planning)**：Agent 需要把一个复杂的大任务拆解成子任务（比如利用 Chain of Thought 或 Tree of Thoughts 算法）。
* **你提到的：**
* **Prompt**（提示词）：是启动和约束大脑思考方式的“元指令”（比如定义它的角色、思考边界、反思机制）。
* **Context**（上下文）：是大脑在当前那一刻所能看到的“即时工作内存”。



### 3. 记忆系统 (Memory) —— **Memory**

大模型本身是无状态的（Stateless），必须给它套上记忆组件。

* **短期记忆 (Short-term Memory)**：通常就是当前的会话历史（In-context Message History），让 Agent 知道前两步聊了什么。
* **长期记忆 (Long-term Memory)**：通常通过向量数据库（Vector DB）或外部存储实现。Agent 通过检索（RAG）把很久以前的知识或用户偏好捞出来，放进 Context 里。

### 4. 动作与工具 (Action & Tools) —— **Tool**

这是 Agent 产生实际影响力的“手和脚”。

* **职责**：大模型光靠思考是无法改变现实的，它必须通过调用外部 API、执行脚本、搜索网页、读写数据库等方式来获取新信息或执行物理操作。
* **你提到的：** **Tool**（工具/插件）就是 Agent 与真实世界交互的媒介。

---

## 🔄 它们是如何协同工作的？（工作流）

一个经典的 Agent 循环（如 ReAct 模式：Reasoning + Acting）通常是这样运转的：

```
 用户请求 (User Input) 
       │
       ▼
 ┌─────────────── LLM Agent 核心大脑 (LLM) ────────────────┐
 │                                                        │
 │  1. 结合 [Prompt] (你是谁) 和 [Memory] (之前聊了什么)    │
 │  2. 在 [Context] 限制内进行推理与规划                  │
 │  3. 决定下一步行动：[Tool] (需要查天气/调 API 吗？)     │
 │                                                        │
 └─────────────────────────┬──────────────────────────────┘
                           │
                 调用工具  │  返回结果 (Observation)
                           ▼
                 ┌───────────────────┐
                 │    Tool 外部工具  │
                 └───────────────────┘

```

## 💡 一点架构上的微调建议

如果你正在设计自己的 AI Agent 框架（比如你之前提到的多层脑结构），在命名和归类上可以这样更清晰地划分：

* **静态/配置层**：`Prompt`（定义行为模式）。
* **动态/数据层**：`Context`（当前帧的输入）和 `Memory`（跨帧的状态维护）。
* **执行/计算层**：`LLM`（思考端 Reasoner/Cognitor）和 `Tool`（执行端 Executor 的一部分）。
